# Project Guidelines & Agent Rules

## Bulk Design & Asset Workflows

### 1. Mandatory Reference Design First
Whenever a task involves bulk design editing, product card updates, or poster/asset generation:
- **Always ask the user for a visual reference design before starting.**
- Acceptable references include:
  - An uploaded reference image (brochure, ad, banner, or catalog).
  - A reference to an existing approved design/asset in the repository.
  - An approved AI-manipulated mock or visual style prototype.
- Never improvise a bulk design format from scratch without confirming the visual direction and style anchors.

### 2. Plan First & Approval Gate
- Always present a detailed plan with the exact copy matrix (headlines, sub-labels, badges), brand palette mappings, and safe margin rules.
- Request user feedback and wait for explicit approval before modifying code or replacing assets.

### 3. Work on an Isolated Branch
- Create and switch to a dedicated git branch (e.g. `feature/<name>-cards`) for all bulk design tasks.
